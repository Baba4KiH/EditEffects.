# ee. — самостоятельный сайт студии

HTML/CSS/JavaScript и Node.js-сервер без npm-зависимостей. Все шрифты и ресурсы оформления локальные. Для отправки заявки сервер обращается к Telegram API.

## Локально

Нужен Node.js 24 (проверен код на установленном Node). Скопируйте `.env.example` в `.env`, заполните токен и ID чата, затем:

```sh
npm test
npm start
```

Откройте http://localhost:3000. Не запускайте HTML двойным щелчком или через статический Live Server: метаданные подставляются сервером, форма использует `/api/brief`.

Полные команды Windows cmd, настройка прокси, переезд на хостинг и незавершённые действия — в **PUBLICATION.txt**.

## Устройство

- `server/config.mjs` — проверка настроек и доверенных прокси.
- `server/handler.mjs` — публичные ресурсы, SEO, ограничения и отправка заявки.
- `server/index.mjs` — HTTP, безопасные журналы ошибок, корректная остановка.
- `site-*.js` — анимации и интерфейс, `form.js` — форма.
- `fonts/` — локальный Manrope и лицензия OFL.
- `deploy/` — примеры HTTPS-прокси Caddy и службы Linux systemd.
- `test/` — проверки с подменённым Telegram API, без реальных сообщений.

Основной сценарий — один Node-процесс за HTTPS-прокси на том же домене. Кеширование ресурсов — час, HTML/API — без кеша. Сжатие выполняет пример Caddy. `/healthz` проверяет доступность процесса, а не доставку в Telegram. Ограничение заявок хранится в памяти процесса: после рестарта сбрасывается, для нескольких экземпляров понадобится общий лимитер.

Публичная раздача работает по списку разрешённых файлов. `.env`, тесты, инструкции и исходники сервера недоступны по HTTP. Не размещайте корень проекта в общедоступной папке другого веб-сервера.
